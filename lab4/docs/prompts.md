# Использование ИИ в лабораторной 4

При работе над лабораторной я использовала Codex для помощи с техническими вопросами, подготовкой workflow, проверкой результатов и оформлением отчёта.

## Примеры задач

Ниже кратко описаны задачи, с которыми помогал ИИ; это пересказ содержания запросов.

- Настройка запуска n8n и Redis через Docker с сохранением данных в локальных папках.
- Подготовка и объяснение кода с массивом, циклом for и условием if/else для ноды Code.
- Проверка обеих ветвей IF, JSON-ответа HTTP Request и автоматических запусков по расписанию.
- Разбор проверки отсутствия ключа Redis, поскольку во встроенной ноде нет операции Exists.
- Оформление отчёта и пояснение работы нод для подготовки к защите.

## Уточнения по работе

Дополнительную ачивку решено не выполнять. Для оформления использован запрос: «В оформлении отчётов опирайся на уже выполненные лабы, они подходят по оформлению».

В самих workflow внешние LLM и AI-ноды не используются: потоки выполняют обычные операции обработки данных и автоматизации.
