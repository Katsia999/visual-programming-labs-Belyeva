# Использование ИИ в лабораторной 4

Для работы использовался Codex. Запросы касались выполнения заданий, выбора дополнительных заданий и оформления. Созданные workflow необходимо понимать и уметь объяснить на защите.

## Основной запрос

«Выполнить лабораторную работу по методичке n8n, установить необходимые компоненты, проверить результат, сделать скриншоты без курсора, сохранять законченные этапы осмысленными коммитами и отправить результат в репозиторий. После выполнения подготовить пошаговое объяснение для защиты».

## Уточнение объёма

На вопрос о выборе индивидуальной ачивки дан ответ: «Ачивку не делать».

## Оформление

«В оформлении отчётов опирайся на уже выполненные лабы, они подходят по оформлению».

## Задачи, решённые с помощью ИИ

- Разбор требований методички и сопоставление их с файлами лабораторной.
- Подготовка конфигурации Docker и workflow с фамилией и группой.
- Проверка JavaScript, HTTP-запроса, расписания и операций Redis.
- Подготовка описания нод и вопросов для защиты.

В n8n не используются платные AI-ноды и внешние LLM: ИИ применялся для подготовки лабораторной, а её потоки выполняют обычные операции автоматизации.
