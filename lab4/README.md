# Лабораторная работа №4 — n8n

Беляева Екатерина, СДП-ИИ-241. Основная часть: 8 workflow, без ачивки.

## Запуск

1. Запустить Docker Desktop и дождаться работающего Engine.
2. В PowerShell из папки `lab4` выполнить `./start.ps1`. В Git Bash: `docker compose up -d`.
3. Открыть [редактор n8n](http://localhost:5678). На этом компьютере аккаунт и потоки уже настроены. Данные входа находятся только в `runtime/owner-account.json`.
4. В списке Workflows открыть нужный поток и нажать Execute. Для демонстрации Redis сначала выполнить 09, затем 10. Поток 06 опубликован и работает раз в минуту.

Версии зафиксированы в Compose: `n8nio/n8n:2.44.6`, `redis:7.4.11`. Данные n8n и Redis хранятся в локальной папке `runtime`, исключённой из Git. Два bind mount n8n: `runtime/n8n` → `/home/node/.n8n`, `runtime/data` → `/data`.

Повторный запуск: `docker compose up -d`. Остановка без удаления данных: `docker compose stop`. Логи: `docker compose logs -f n8n`.

## Импорт на другом компьютере

После первого запуска создать локального владельца n8n. Через меню workflow → Import from File импортировать отдельные JSON из `flows`. Для 09 и 10 создать Redis credential: Host `host.docker.internal`, Port `6379`, Database `0`, без пароля и SSL, затем выбрать credential в обеих Redis-нодах. В текущей установке credential уже назначен.

Для автоматического расписания открыть 06 и нажать Publish. Ручные потоки 01–05, 09–10 достаточно сохранить и запускать кнопкой Execute: постоянного внешнего триггера у них нет.
