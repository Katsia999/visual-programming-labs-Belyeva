## Результат

Каркас создан Bubble AI. Заголовок, цветовая переменная, новый стиль и компонент настроены вручную. Тип MealPlan с пятью полями четырёх типов и три начальные записи добавлены вручную. Для новой сущности создана отдельная страница с полным CRUD. В Preview проверены сохранение после перезагрузки, просмотр, изменение, удаление выбранной тестовой записи и отклонение некорректных значений.

Для демонстрации откройте dev-версию. Для изменения приложения войдите в аккаунт владельца Bubble. Локальный сервер и установка зависимостей не нужны. Приложение работает в Development; публикация в Live для этой работы не выполнялась.
