# Промпты для Bubble

Первый промпт отправлен в Bubble 15.10.2026. Остальные тексты подготовлены для следующих этапов; факт отправки и результат отмечаются в отчёте после выполнения.

## 1. Первичная генерация

```text
Создай приложение на тему «Каталог рецептов» с названием «Книга рецептов».
Пусть этот сайт будет публичным, без обязательной регистрации.
Страницу обязательно создай по структуре header + body + footer.
Обязательно укажи в заготовке следующую строку: «ТВП: Беляева».
Добавь несколько интерактивных элементов, реализующих CRUD для рецептов: создание, просмотр, редактирование и удаление.
Интерфейс должен быть на русском языке. На главной странице размести заголовок «Книга рецептов», поиск по названию, список рецептов и кнопку добавления рецепта. Для рецепта используй название, описание, ингредиенты и время приготовления в минутах.
Используй спокойное светлое оформление с зелёным акцентом и удобную адаптивную компоновку. В подвале повтори строку «ТВП: Беляева».
```

## 2. Новая сущность для части 4

```text
Предложи название и поля новой сущности для приложения Bubble «Каталог рецептов». Эта сущность должна отличаться от Recipe, созданной при первичной генерации. Нужна сущность для планирования приготовления блюда: название блюда, запланированная дата, отметка о приготовлении, количество порций и заметка. Укажи английские имена полей Bubble и их типы; нужны минимум три разных типа. Не создавай сущность автоматически: я добавлю её вручную в Data и внесу три записи через App Data.
```

Ответ внешнего AI для ручного создания:

| Поле MealPlan | Тип Bubble | Назначение |
| --- | --- | --- |
| title | text | Название блюда |
| planned_date | date | Дата приготовления |
| is_cooked | yes/no | Приготовлено ли блюдо |
| servings | number | Количество порций |
| notes | text | Заметка |

## 3. Новая страница с CRUD

```text
В этом же приложении создай новую страницу meal_plans для уже существующего типа данных MealPlan. Не создавай второй тип с тем же назначением. Интерфейс на русском языке, структура header + body + footer, ссылка на главную и строка «ТВП: Беляева» в подвале.
Добавь форму с полями title (text), planned_date (date), is_cooked (yes/no), servings (number), notes (text). Добавь Repeating Group со списком MealPlan, выводом полей и кнопками «Просмотреть», «Изменить», «Удалить» для выбранной записи.
Создай отдельные workflows: «Создать» создаёт MealPlan из формы; «Просмотреть» показывает выбранную запись в группе подробностей; «Сохранить изменения» меняет только выбранный MealPlan; «Удалить» удаляет только выбранный MealPlan после подтверждения. Для удаления используй только демонстрационные записи этого приложения.
Не разрешай сохранение пустого названия и количества порций меньше 1. Сортируй список по planned_date. После создания и сохранения очищай форму; добавь отмену редактирования. Не используй внешние API или платные плагины.
```
