\# Flowchart



```mermaid

flowchart TD

&#x20;   A(\[Начало]) --> B\[Клиент выбирает ресторан и блюда]

&#x20;   B --> C\[Клиент оформляет заказ]

&#x20;   C --> D\[Приложение отправляет заказ в ресторан]

&#x20;   D --> E\[Ресторан проверяет наличие блюд]

&#x20;   E --> F{Все блюда доступны?}



&#x20;   F -->|Нет| G\[Приложение уведомляет клиента]

&#x20;   G --> H{Клиент хочет изменить заказ?}

&#x20;   H -->|Да| C

&#x20;   H -->|Нет| I\[Отменить заказ]

&#x20;   I --> Z(\[Конец])



&#x20;   F -->|Да| J\[Клиент выбирает способ оплаты]

&#x20;   J --> K\[Платёжная система обрабатывает оплату]

&#x20;   K --> L{Оплата успешна?}



&#x20;   L -->|Нет| M\[Повторить оплату или выбрать другой способ]

&#x20;   M --> J



&#x20;   L -->|Да| N\[Ресторан начинает готовить еду]

&#x20;   L -->|Да| O\[Система ищет свободного курьера]



&#x20;   N --> P\[Ресторан упаковывает заказ]

&#x20;   P --> Q\[Статус: Готов к выдаче]



&#x20;   O --> R\[Назначить курьера]



&#x20;   Q --> S\[Курьер приезжает в ресторан]

&#x20;   R --> S



&#x20;   S --> T\[Курьер подтверждает получение заказа]

&#x20;   T --> U\[Курьер доставляет заказ клиенту]

&#x20;   U --> V\[Клиент подтверждает получение]

&#x20;   V --> W\[Приложение завершает заказ]

&#x20;   W --> X\[Предложить оставить отзыв]

&#x20;   X --> Z(\[Конец])

```
