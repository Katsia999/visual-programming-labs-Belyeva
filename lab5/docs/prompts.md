# Использование ИИ

1. «Изучи методичку лабораторной 5 и выбери трек, который можно полностью выполнить локально без платных интеграций».
2. «Русифицируй официальный шаблон Lead Generation для заявки на консультацию по лабораторным. Сохрани связи блоков и идентификаторы переменных».
3. «Добавь ввод группы, условие для СДП-ИИ-241, переменные результата и HTTP Request. Предусмотри понятное сообщение при ошибке запроса».
4. «Проверь опубликованного бота: обе ветви Condition, ошибочную почту, сохранение заявки и получение данных HTTP. Скриншоты должны быть настоящими и без курсора».
5. «Подготовь отчёт по образцу предыдущих лабораторных и отдельное пошаговое объяснение каждого блока для защиты».

Codex использовался для разбора требований, подготовки конфигурации, перевода шаблона, изменения JSON, проверки работы и объяснения результата. Исходный шаблон предоставлен Typebot; фактические результаты проверяются в запущенной платформе.
